# Asset licences

Everything in this folder is cleared for commercial use on a monetised channel.
That is not caution for its own sake: Instagram and YouTube both run automated
content-ID against uploads, and a strike on a personal-brand account is far
more expensive than the ten minutes it takes to source properly.

| Folder | Source | Licence |
| --- | --- | --- |
| `images/` | Pexels | Pexels Licence — free for commercial use, no attribution required, no model releases needed for editorial-style use |
| `music/` | see per-file note below | free-for-commercial, attribution as noted |
| `sfx/` | generated locally | none — synthesised, not sampled |
| `vo/` | Microsoft Edge neural TTS | free |
| `textures/` | generated locally | none — synthesised |

Per-file provenance is recorded in `SOURCES.txt` as files are added, so this
never becomes a folder of images nobody can account for.
